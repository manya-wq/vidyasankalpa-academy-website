# Deployment Notes

This is a static HTML/CSS/JS site.

1. Upload the project root exactly as provided.
2. Keep `assets/`, `css/`, and `js/` beside the HTML pages.
3. Configure the host to serve `index.html` for `/`.
4. Configure `404.html` as the custom 404 page when supported.
5. Before public launch, add the academy's official Instagram, Facebook, LinkedIn and YouTube profile URLs to the footer social buttons. The build intentionally does not invent those URLs.
6. Replace the WhatsApp flow with a backend/CRM endpoint if the academy later needs stored lead management.
