# Vidyasankalpa Academy Website

Official frontend website for Vidyasankalpa Academy, Mysuru.

## About

Vidyasankalpa Academy provides integrated academic and competitive examination support for PUC students, focusing on conceptual learning, regular practice, testing, analysis, and improvement.

## Features

- Responsive modern website
- Academy overview
- About Academy
- CET, NEET and PUC Programs
- Academic Methodology
- Admissions Information
- Counselling CTA
- Contact Information
- Google Maps Integration
- WhatsApp Floating Button
- Back-to-Top Button
- Responsive Navigation
- Mobile-Friendly Design
- Custom 404 Page

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Pages

- Home
- About
- Programs
- Academics
- Admissions
- Contact
- 404 Error Page

## Local Development

Clone the repository:

git clone https://github.com/manya-wq/vidyasankalpa-academy-website.git

Open the project in VS Code and run it using Live Server or open `index.html` directly in a browser.

## Git Workflow

Create a new branch for development:

git switch main
git pull origin main
git switch -c feature-name

After making changes:

git add .
git commit -m "Describe your changes"
git push -u origin feature-name

Create a Pull Request and merge it into `main` after review.
