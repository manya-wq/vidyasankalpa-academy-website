# Vidyasankalpa Academy — Production Static Rebuild

Pure HTML, CSS and Vanilla JavaScript. No framework or build step required.

## Pages
- index.html
- about.html
- programs.html
- faculty.html
- admissions.html
- contact.html
- terms.html
- 404.html

## Assets
All academy/faculty imagery is sourced from the supplied client asset pack and optimized to WebP.

## Run locally
Use any static server, for example:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173/`.

## Deployment
Upload the folder contents to Netlify, Cloudflare Pages, GitHub Pages, Vercel static hosting, Apache or Nginx.
